## 2. Idea de desarrollo web

**Perfumería GOLD** es una aplicación web para la venta de perfumes y la administración de una perfumería. Permite a los clientes consultar productos, agregarlos al carrito y realizar pedidos. También ofrece un panel administrativo para gestionar productos, inventario, clientes, proveedores, ventas y reportes.

## 3. Requerimientos funcionales (épicas e historias de usuario)

### Épica 1. Gestión de usuarios
- **HU-01:** Como cliente, quiero registrarme e iniciar sesión para acceder a mi cuenta.
- **HU-02:** Como cliente, quiero actualizar mis datos personales para mantener mi información al día.

### Épica 2. Catálogo de perfumes
- **HU-03:** Como cliente, quiero visualizar el catálogo de perfumes con sus precios y características para elegir un producto.
- **HU-04:** Como cliente, quiero buscar y filtrar perfumes para encontrar fácilmente el que necesito.

### Épica 3. Carrito y pedidos
- **HU-05:** Como cliente, quiero agregar o eliminar perfumes del carrito para organizar mi compra.
- **HU-06:** Como cliente, quiero confirmar un pedido y consultar su estado para hacer seguimiento a mi compra.

### Épica 4. Administración e inventario
- **HU-07:** Como administrador, quiero registrar, editar y eliminar productos para mantener actualizado el catálogo.
- **HU-08:** Como administrador, quiero consultar y actualizar el inventario para controlar las existencias.
- **HU-09:** Como administrador, quiero gestionar proveedores para organizar el abastecimiento de productos.

### Épica 5. Ventas y reportes
- **HU-10:** Como cajero, quiero registrar ventas presenciales para llevar el control de caja.
- **HU-11:** Como administrador, quiero consultar reportes de ventas para conocer el rendimiento del negocio.

## 4. Requerimientos no funcionales (Definition of Done)

### Requerimientos no funcionales
- **RNF-01:** La interfaz debe ser fácil de usar y adaptable a computadores y dispositivos móviles.
- **RNF-02:** El sistema debe proteger las contraseñas y restringir las funciones administrativas a usuarios autorizados.
- **RNF-03:** El sistema debe validar los datos ingresados para evitar errores e inconsistencias.
- **RNF-04:** Las páginas y consultas deben tener tiempos de respuesta adecuados.

### Definition of Done (criterios para dar una historia por terminada)
- [ ] La funcionalidad está implementada y cumple la historia de usuario.
- [ ] Se verificó su funcionamiento y se corrigieron los errores encontrados.
- [ ] La interfaz funciona correctamente en computador y celular, cuando aplica.
- [ ] Se validan los datos y se respetan los permisos de acceso.
- [ ] Los cambios están guardados en el repositorio de GitHub.

- **HT-01:** Como equipo de desarrollo, necesitamos utilizar **Node.js y Express** para implementar el servidor y las rutas de la aplicación.
- **HT-02:** Como equipo de desarrollo, necesitamos utilizar **EJS, HTML, CSS y JavaScript** para construir las interfaces del sistema.
- **HT-03:** Como equipo de desarrollo, necesitamos utilizar **MySQL y Sequelize** para almacenar y consultar la información.
- **HT-04:** Como equipo de desarrollo, necesitamos implementar autenticación, sesiones y roles para controlar el acceso.
- **HT-05:** Como equipo de desarrollo, necesitamos organizar el código en modelos, vistas, controladores y rutas para facilitar su mantenimiento.
- **HT-06:** Como equipo de desarrollo, necesitamos usar **Git y GitHub** para gestionar las versiones y el trabajo del equipo.
